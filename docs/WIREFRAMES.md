# Wireframes

## Navegação pública mobile-first

```text
┌──────────────────────────────┐
│ BemDoar                 Conta│
├──────────────────────────────┤
│ Doar amor,                   │
│ espalhar esperança.          │
│ [ Quero ajudar ]             │
├──────────────────────────────┤
│ Necessidades em destaque     │
│ ┌──────────────────────────┐ │
│ │ Categoria · Prioridade   │ │
│ │ Título                   │ │
│ │ Progresso █████░░ 65%    │ │
│ │ [ Ver detalhes ]         │ │
│ └──────────────────────────┘ │
├──────────────────────────────┤
│ Início  Necessidades  Perfil │
└──────────────────────────────┘
```

## Fluxo de doação

```text
Necessidade -> Detalhes -> Quero doar -> Formulário -> Confirmação
```

## Área administrativa

```text
┌─────────────────────────────────────────┐
│ Menu | Gestão de doações                │
├─────────────────────────────────────────┤
│ Filtros: [situação] [buscar]             │
│ Pendente   Usuário   Item   [Confirmar] │
│ Confirmada Usuário   Item   [Receber]   │
└─────────────────────────────────────────┘
```

Os wireframes registram hierarquia e fluxo, não medidas visuais finais. A implementação responsiva está em `frontend/src`.
